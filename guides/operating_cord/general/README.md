# General Info

This section of the guide describes tools for interacting with CORD. These tools generally interact with CORD over a variety of APIs that are described [here](../api/). Most notably:

* A graphical interface is documented [here](gui/).
* A command-line interface, [cordctl](https://github.com/hyunsun/docs/tree/a7c57608e40a8306309625802fa069c38c3d1d8a/cordctl/README.md), can be used to interact with the CORD data model and perform high-level operations such as backup and restore.
* A text shell, [XOSSH](https://github.com/hyunsun/docs/tree/a7c57608e40a8306309625802fa069c38c3d1d8a/xos/dev/xossh.md), can be used to operate on objects in the CORD data model.
