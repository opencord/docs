# Operations Guide

This guide defines various processes, procedures, and tools for operating a CORD POD. It assumes the [install](../readme/) is already complete, and you want to operate and manage a running POD.

Note that the first step in operating a POD is to provision and configure the set of _Services_ included in the selected _Profile_. Configuration details are specified in the follow two References:

* [Configuring Profiles](../../references/intro/)
* [Configuring Services](../../references/services/)

Default configurations are currently loaded into the POD at installation time.
